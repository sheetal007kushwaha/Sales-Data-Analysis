# Sales-Data-Analysis
beginner-friendly sales data analysis project using Python.
Sales Data Analysis Using Python

About the Project

This project focuses on analysing sales data using Python. It helps to understand product performance and total sales through simple data analysis.

Tools Used

- Python
- Pandas
- Matplotlib

Project Features

- Reading sales data from a CSV file.
- Calculating total sales and revenue.
- Analysing product-wise sales.
- Finding the best-selling product.
- Creating a bar chart for data visualization.

Files

- sales_data.csv – Contains sample sales records.
- analysis.py – Python code for sales analysis.

Learning Outcome

Through this project, I learned basic data analysis, data handling and visualization using Python.
